# 🔥 Resume Roaster AI

> Upload your resume. Get brutally (and hilariously) roasted. Actually improve it.

Resume Roaster is a single-file AI-powered web app that analyzes your resume and delivers savage, constructive feedback using Claude AI. Pick your roast mode, upload your PDF, and brace yourself.

---

## ✨ Features

- **5 Roast Modes** — Soft Coach, Ruthless Recruiter, FAANG Committee, HR Demon, and LinkedIn Guru
- **AI Scoring** — Get rated on ATS Compatibility, Recruiter Appeal, Clarity, Impact, and Cringe Factor
- **Ghost Probability** — Find out how likely you are to never hear back
- **Shame Badges** — Earn badges like *Buzzword Warrior*, *Passive Voice Bandit*, and *PDF Criminal*
- **Rewrite Suggestions** — Before/after bullet point rewrites that actually sound human
- **One-Click Actions** — Request a full rewrite, ATS keyword analysis, or a matching cover letter
- **Zero backend** — Runs entirely in the browser as a single `.html` file

---

## 🚀 Getting Started

### Prerequisites

- An [Anthropic API key](https://console.anthropic.com/)

### Usage

1. Clone or download this repository
2. Open `resume_roaster_app.html` in any modern browser
3. Upload your resume (PDF or image)
4. Select your target role and roast mode
5. Click **ROAST MY RESUME** and prepare for the truth

> **Note:** The app calls the Anthropic API directly from the browser. Make sure your API key has access to `claude-sonnet-4-20250514`.
